# Tibetan Typing — Grammar Course (Beta)

Static website for GitHub Pages.

## Deploy
1. Create a public GitHub repository `tibetan-typing-beta`.
2. Upload `index.html` and `.nojekyll` to repository root (unzip this archive first).
3. Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save.
4. Open `https://YOUR-USERNAME.github.io/tibetan-typing-beta/` after deployment completes.

## Updating
Upload a new `index.html` to the same `main` branch. GitHub Pages will redeploy to the same URL. Keep a copy of prior versions and test browser-local progress before releases. Avoid changing localStorage keys across releases.

## Notes
This is a public beta, not content-reviewed. The page loads a Google Fonts stylesheet; fully offline font loading isn't guaranteed. GitHub Pages is public even during beta testing. Test Tibetan input methods, virtual keyboard, grammar exercises, progress and backups.
